Установка AvaWeather

AvaWeather — настольное погодное приложение для Windows, macOS и Linux. Скачайте сборку для своего процессора из последнего релиза на GitHub. В сборки уже включён .NET, отдельно устанавливать его не нужно.

Windows

Для большинства компьютеров с Intel и AMD выберите установщик x64, а для Windows на ARM — установщик ARM64. Запустите файл и следуйте подсказкам. Установщик добавит AvaWeather в меню «Пуск», предложит ярлык на рабочем столе и зарегистрирует удаление в настройках Windows.

Если установка не нужна, скачайте отдельный файл x64 или файл ARM64 и запустите его. Установщик пока не подписан доверенным издателем, поэтому Windows может запросить подтверждение запуска.

macOS

Для Mac с процессором серии M скачайте пакет Apple Silicon, а для Mac с Intel — пакет Intel. Откройте пакет и завершите установку: AvaWeather.app появится в папке «Программы».

Также доступны отдельные исполняемые файлы для Apple Silicon и Intel. Для запуска отдельного файла из Терминала сначала выполните chmod +x AvaWeather-osx-arm64 (для Intel замените имя файла). Пакет не подписан Apple Developer ID; macOS может попросить подтвердить запуск в настройках безопасности.

Linux

Скачайте архив x64 или архив ARM64. Распакуйте его и запустите файл AvaWeather. Например, из каталога распаковки выполните ./AvaWeather. Отдельного установщика Linux нет.

Версия для браузера

Если устанавливать приложение не хочется, откройте AvaWeather в браузере. Для сайта нужны JavaScript и WebAssembly. Возможности прогноза и определение местоположения описаны на странице о приложении.
