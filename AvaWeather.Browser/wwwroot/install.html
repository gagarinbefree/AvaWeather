Install AvaWeather

AvaWeather is a desktop weather app for Windows, macOS and Linux. Download the build for your processor from the latest GitHub release. The desktop builds include .NET, so you do not need to install the runtime separately.

Windows

Choose the x64 installer for most Intel and AMD PCs, or the ARM64 installer for Windows on ARM. Run the installer and follow its prompts. It adds AvaWeather to the Start menu, offers a desktop shortcut and registers an uninstall entry in Windows settings.

For a standalone download, use the x64 executable or ARM64 executable and run it directly. The installer is not signed by a trusted publisher, so Windows may ask you to confirm the launch.

macOS

Download the Apple Silicon package for M-series Macs or the Intel package for older Macs. Open the package and complete the installer; it places AvaWeather.app in Applications.

You can instead download the standalone Apple Silicon executable or Intel executable. If you run a standalone file from Terminal, make it executable first with chmod +x AvaWeather-osx-arm64 (use the matching Intel filename if needed). The installer is not signed with Apple Developer ID; macOS may request confirmation in its security settings.

Linux

Download the x64 archive or ARM64 archive. Extract it and run the included AvaWeather executable. For example, from the extracted directory run ./AvaWeather. There is no separate Linux installer.

Use the browser version

Open AvaWeather online if you do not want to install an app. The site requires JavaScript and WebAssembly. For an overview of the forecast and how location is detected, read about AvaWeather.
