AvaWeather — погода по вашему местоположению

AvaWeather показывает погоду поблизости без ручного поиска города. Откройте прогноз в браузере или установите настольное приложение для Windows, Linux либо macOS.

Открыть прогноз погоды

Что есть в прогнозе

  • Текущая температура, ощущаемая температура, влажность, ветер, УФ-индекс, давление и видимость.
  • Почасовой прогноз на оставшуюся часть сегодняшнего и на завтрашний день, включая вероятность осадков.
  • Прогноз на три дня с максимальной и минимальной температурой, вероятностью дождя, ветром, временем восхода и заката.

Как определяются местоположение и язык

AvaWeather определяет примерное местоположение по IP-адресу. GeoJS сообщает координаты, а WeatherAPI предоставляет текущую погоду и прогноз. Если GeoJS недоступен, WeatherAPI может определить местоположение по IP. Интерфейс автоматически выбирает русский или английский язык по определённой стране.

Скачать AvaWeather

Настольные сборки находятся на странице последнего релиза. Выберите установщик или автономный файл для своей системы:

  • Windows: установщик x64 или установщик ARM64.
  • macOS: установщик для Intel или установщик для Apple Silicon.
  • Linux: сборка x64 или сборка ARM64.

Веб-версия работает на GitHub Pages и требует JavaScript и WebAssembly. Настольное приложение работает без браузера.
